Guía Metodológica SOC — Escaneo, CMDB, SBOM y Triaje CVE

Referencia rápida para estudiantes y docentes sobre los conceptos operativos del simulador.

1. Escaneo Activo vs. Pasivo

El Escaneo Activo (nmap -sS -sV) envía sondas TCP SYN para enumerar puertos y banners, pero genera ruido y activa sistemas IPS/Honeypot. El Escaneo Pasivo (tshark) escucha broadcasts ARP, mDNS y SSDP/BACnet sin transmitir paquetes, revelando IoT, Shadow IT y servidores con firewall estricto.

2. CMDB y Mapeo de CIs

Una CMDB consolida los Elementos de Configuración (CIs) legítimos tras su validación. El CI Mapping muestra el impacto en cascada (por ejemplo, cómo un frontal web depende de Tomcat/Log4j, una base de datos y el hypervisor físico) y el aislamiento cuando un nodo pasa a En Cuarentena.

3. SBOM (CycloneDX) y Correlación CVE

Un SBOM (Software Bill of Materials) lista cada paquete y versión instalado (log4j-core-2.14). Al cruzarlo contra bases CVE y el catálogo CISA KEV (vulnerabilidades explotadas activamente), el SOC prioriza qué parchear según vector CVSS v3.1 y subred afectada.

4. Triaje de Falsos Positivos y Portabilidad

No toda coincidencia CVE implica explotación real (ej. funcionalidad deshabilitada o mitigación compensatoria). Marcar Falso Positivo / Riesgo Aceptado recalcula el riesgo global. Con Exportar/Importar Base64, los profesores comparten escenarios listos para evaluar.
